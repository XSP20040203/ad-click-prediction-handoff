# 分数口径

| 指标 | 含义 | 能否当17号平台成绩 |
| --- | --- | --- |
| platform_auc_user_reported | 用户反馈的平台显示分数 | 是用户反馈记录；未独立获取标签核算 |
| 15/16日真实开发AUC | train.csv真实标签上的按天验证 | 不能代表17号；开发日期已多次复用 |
| 对猜测标签的本地AUC | 提交概率与猜测的0/1向量计算ROC AUC | 不能，标签是假设且常被用于选择预测 |
| 软排名矩指标 | 条件概率与排名构成的线性预期矩 | 不是二进制ROC AUC或已校准的平台预测 |
| 目标/阈值 | 想达到的0.85/0.83/0.815等 | 不是已测量结果 |

平台反馈按普通全量ROC AUC、显示值四舍五入保留五位小数解释；该解释是分析假设。
用户此前确认全部17号样本参加评分，但没有提供真实标签或正例总数。
两个显示分数相同不证明未舍入的真实分数完全相等。AUC也不随概率加权线性插值。

不能把其中的目标、预期矩或伪标签指标与平台成绩一起排序。
